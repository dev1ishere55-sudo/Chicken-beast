# Chickenbeast Miner ($CBEAST)

TOO JACKED TO RUG. Tap-to-earn gym game: tap the beast, buy supplements, hatch passive gains.

- Rules live in `convex/lib/gameRules.ts` and run on both server (authoritative) and client (practice mode).
- Saved progress in `convex/game.ts` (players table).
- UI in `src/pages/Index.tsx` with state in `src/pages/_hooks/use-beast-game.ts`.

Beast Points are game points, not tokens.
